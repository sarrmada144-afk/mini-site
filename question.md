# Réponses aux Questions de TP

## 1. Quelle est la différence entre Git et GitHub ?

Git est un logiciel de gestion de versions installé sur l’ordinateur.
GitHub est une plateforme en ligne permettant d’héberger les projets Git.

---

## 2. À quoi sert la commande git init ?

La commande git init permet d’initialiser un projet Git dans un dossier.

---

## 3. Quelle commande permet d’envoyer un projet sur GitHub ?

La commande utilisée est :

git push -u origin main

---

## 4. Pourquoi utilise-t-on les branches ?

Les branches permettent de travailler sur différentes fonctionnalités sans modifier le projet principal.

---

## 5. Quelle commande permet de voir l’historique des commits ?

La commande utilisée est :

git log
